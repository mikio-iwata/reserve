# 予約・キャンセルシステム レスポンシブ対応 テスト実施手順 v2（browser 権限あり / Codex 用）

本書は **Codex に実ブラウザ操作権限がある前提**の実施手順。前回（v1）の「静的確認を合格扱い」した反省を踏まえ、
**「証拠（スクショ・数値）が無い判定は禁止」「実機がない環境を合格にしない」** を絶対ルールとする。

対象ファイル: `_reserve` 配下（`index.asp` / `main.asp` / `reserve.asp` / `error.asp`）
結果記入先: `予約システム_レスポンシブ対応_テスト仕様書.xlsx`（同ディレクトリ）

---

## 0. 絶対ルール（違反した結果は無効）

1. **証拠主義**: 判定「合格／不合格」を付けるには、必ず **スクリーンショット** または **数値計測ログ** を残す。証拠が無い項目は **「未実施」** とする。捏造・推測での合格は厳禁。
2. **エンジンを偽らない**: Chromium で Safari/iOS を「代替確認」しない。WebKit は別エンジン。実機/クラウド実機が無いものは **「対象外」** とし、理由を明記。
3. **静的確認 ≠ 合格**: コードを読んだだけのものは合格にしない。必要なら判定欄は「未実施」、メモに「静的確認のみ（参考）」と書く。
4. **自己申告の限界明記**: エミュレーションで確認したものは、メモに「DevToolsエミュレーション（実機未確認）」と必ず付す。

## 1. 実施範囲（権限ありでも分ける）

| 区分 | ブラウザ | 実施方法 | 判定可否 |
|---|---|---|---|
| ✅ 自動実施 | Win Chrome / Win Edge / Win Firefox | 実ブラウザ操作＋スクショ＋JS計測 | 合格/不合格を付けてよい |
| 🟡 条件付き | iOS Safari / Android Chrome / iPad Safari | **実機 or BrowserStack 等がある場合のみ**実施 | 無ければ「対象外（実機なし）」 |
| 🔴 禁止 | 上記モバイルを Chromium エミュレーションで「合格」 | — | 不可。やるなら判定は付けずメモに参考所見のみ |

> モバイル実機/クラウドが用意できない場合は、その旨を概要シートに明記し、対象外のまま提出する（正直であることが品質保証の前提）。

## 2. 証拠（エビデンス）の残し方

- 保存先: `_reserve/test_evidence/` を作成し、ここに格納。
- ファイル名規則: `<テストID>_<ブラウザ>_<幅>.png`
  例: `A-012_WinChrome_375.png` / `C2-10_WinChrome_1280_after.png`
- 各判定行の **メモ欄に証拠ファイル名と計測値** を記載する。
  例: 「scrollWidth=375, clientWidth=375 → 横スクロール無。evidence: A-002_WinChrome_375.png」
- 機能テストは **操作前/操作後** の2枚（遷移・DB反映の確認）。

## 3. 客観的な合否基準（主観を排除）

## 5. Excel への記入（書式・プルダウンを壊さない）

openpyxl で開いて保存。許可値以外は入れない。

**A_表示・レスポンシブ**（記入列のみ）
- 8列=判定（`合格`/`不合格`/`対象外`/`未実施`）
- 9列=不具合/メモ（**証拠ファイル名・計測値を必ず記載**）
- 10列=実施者, 11列=実施日

**C_機能回帰**
- 6列=ブラウザ, 7列=判定, 8列=メモ（証拠）, 9列=実施者, 10列=実施日
- グループ見出し行（テストID空欄・背景色付き）はスキップ

**不具合一覧**
- No / 関連テストID / 画面 / ブラウザ・幅 / 不具合内容 / 重大度(高中低) / 起票日 / 対応状況 / 対応内容 / 再テスト結果
- 既存 BUG-001〜003 は残し、新規は連番で追記

```python
from openpyxl import load_workbook
p = r"予約システム_レスポンシブ対応_テスト仕様書.xlsx"
wb = load_workbook(p)
wsA = wb["A_表示・レスポンシブ"]
for row in wsA.iter_rows(min_row=2):
    if row[0].value is None:
        continue
    # 実ブラウザで計測・スクショ取得した結果のみ記入
    row[7].value = "合格"  # 証拠が無ければ "未実施"
    row[8].value = "scrollWidth=375<=innerWidth=375。evidence: A-002_WinChrome_375.png"
    row[9].value = "Codex"
    row[10].value = "2026/06/08"
wb.save(p)
```
